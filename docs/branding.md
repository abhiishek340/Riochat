# Customizing the branding

Riochat has no hard-coded product name in the interface. What users see comes
from three places, each independent of the others.

## 1. Identity: the `branding` section

Set these in the YAML configuration file (they are not environment variables
and not admin-console settings). A blank value falls back to the default.

```yaml
branding:
  title: Acme Assistant
  short_name: Acme
  description: Our internal multi-model assistant.
  logo_url: /assets/acme-logo.svg
  favicon_url: /assets/acme-favicon.ico
  pwa_icon_192_url: /assets/acme-192.png
  pwa_icon_512_url: /assets/acme-512.png
  pwa_maskable_icon_512_url: /assets/acme-maskable-512.png
  apple_touch_icon_180_url: /assets/acme-180.png
```

| Key | Default | Where it appears |
|---|---|---|
| `title` | `Riochat` | Browser tab title, header, sign-in page, manifest `name`. |
| `short_name` | `Riochat` | Home-screen label, manifest `short_name`, application-name meta. |
| `description` | `Riochat is a multi-model AI conversation system.` | Description meta tag and manifest. |
| `logo_url` | empty (built-in mark) | Logo image in the shell and sign-in page. |
| `favicon_url` | `/favicon.ico` | Tab icon. |
| `pwa_icon_192_url` | `/pwa/icon-192.png` | 192 px install icon. |
| `pwa_icon_512_url` | `/pwa/icon-512.png` | 512 px install icon. |
| `pwa_maskable_icon_512_url` | `/pwa/icon-maskable-512.png` | 512 px maskable install icon (keep the artwork inside the central safe zone). |
| `apple_touch_icon_180_url` | `/pwa/apple-touch-icon.png` | iOS home-screen icon. |

Icon values may be absolute URLs or paths. A path is served by whatever hosts
it: either files you add to the web export (see below) or another origin. In
the web app manifest, relative paths are turned into absolute URLs using
`PUBLIC_WEB_BASE_URL`, so set that variable when you use relative icon paths.

The web client reads `GET /api/v1/branding` at start and rewrites the document
head (title, description, icons, manifest link). Changes to the file take effect
after a server restart; browsers may cache the previous icons for a while. The
manifest is generated by the server at `/api/v1/branding/manifest.webmanifest`
and `/manifest.webmanifest`.

Interface text never spells the product name directly. Every message receives a
`{brand}` argument holding the title, so a new `title` renames the product
everywhere, in both languages.

## 2. Default icon files

The stock icons are plain files in `web/public/`: `icon.svg`, `favicon.ico`,
`riochat-icon.svg` and `pwa/*.png`. To ship your own without pointing at another
origin, replace those files (keeping names) or add new files under
`web/public/` and reference them from the `branding` section, then rebuild the
web client (`pnpm build`). `pnpm icons` regenerates the stock set from the
script in `web/scripts/generate-icons.mjs`; edit that script to produce
your artwork.

## 3. Colour: mode and accent

Colours are CSS variables defined in `web/src/app/globals.css` using OKLCH.
Neutrals are shared; one accent hue and chroma drive every coloured surface.
Users choose light, dark or system, and one of four accents (`tide`, `ember`,
`moss`, `dusk`), which are remembered per device.

To change the palette, edit the accent blocks:

```css
[data-accent="tide"]  { --accent-hue: 200; --accent-chroma: 0.1;  }
[data-accent="ember"] { --accent-hue: 45;  --accent-chroma: 0.15; }
```

To add a preset, add a block for the new name, add the name to `ACCENTS` in
`web/src/lib/theme/config.ts`, and add its label next to the existing ones in
`web/src/lib/i18n/catalog/<locale>/shell.ts`. To change the default, change
`DEFAULT_ACCENT` there. Use semantic classes (`bg-card`,
`text-muted-foreground`) in components, never raw colours, so a preset change
carries through.

## Checklist for a rebrand

1. Set `branding.*` in the YAML file and `PUBLIC_WEB_BASE_URL`.
2. Replace or add icon files in `web/public/` and rebuild the web client.
3. Adjust the accent hue and chroma if the default does not suit.
4. Restart the server and hard-reload a browser to check the tab title, icons
   and the install prompt.
